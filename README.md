## 🧩 Organização

O projeto utiliza uma estrutura modular para manter o código organizado e facilitar futuras alterações.

### CSS

Os arquivos CSS são divididos de acordo com sua responsabilidade:

* **base/** — estilos globais, reset e variáveis do projeto.
* **components/** — componentes reutilizáveis da interface, como botões, header e menu.
* **sections/** — estilos específicos de cada seção da página.
* **responsive/** — regras responsáveis pela adaptação da interface para diferentes tamanhos de tela.
* **main.css** — responsável por centralizar e importar os estilos necessários.

### JavaScript

O JavaScript também é organizado de forma modular:

* **main.js** — ponto de entrada da aplicação.
* **modules/** — funcionalidades individuais da página, como navegação, tema, carrossel, accordion e animações.

Essa organização permite que cada funcionalidade tenha sua própria responsabilidade, tornando o código mais fácil de entender, modificar e reutilizar.
